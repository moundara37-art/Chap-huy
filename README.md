# Debt Book • ហាង ពៅមារី

Project includes:
- Supabase login with persistent session
- Shop name + background settings
- Edit debt/payment History
- Khmer History PDF export
- Shop app icon and background

## PDF fix
The PDF capture element stays inside the viewport and waits for fonts/render frames before html2pdf captures it. This fixes blank PDFs on iPhone/Safari.
